# Artwork for this update

All five production assets were created with the built-in image-generation tool. No API or CLI fallback was used. The gameplay platforms, character customization and character animation are rendered by the game's own code.

The original campus panorama and previous gym artwork remain in the project. The expanded sky is a separate layer; foreground cloud and balloon artwork retains its alpha transparency.
